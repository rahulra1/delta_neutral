Connect Delta Exchange

India · Crypto Options & Futures · 24/7 Trading

What you'll need: A Delta Exchange India account with API access enabled. If you don't have one, create an account here. Make sure to complete KYC verification.
1
Go to Delta Exchange API Keys page
Login to your Delta Exchange account and navigate to
Account → Manage API Keys
2
Create a new API Key
Click "Create New API Key". Enter a name like DeltaNeutralBot.
3
Whitelist your IP address
In the "Whitelisted IPs" field, add 110.10.4.5
⚠️ Without IP whitelisting, API calls will be rejected by Delta Exchange.
4
Enable Trading permissions
Make sure to enable "Trading" in the permissions section, then click "Create API Key".
5
Verify and save your keys
Enter the verification code sent to your email and your 2FA code. Once verified, your API Key and API Secret will be displayed.
🔑 Save both keys somewhere safe — the secret won't be shown again!
6
Paste your keys below
Copy the API Key and API Secret from Delta Exchange and paste them in the form below.
